# 🔊 ESP8266 Sound Detection System

A simple IoT project using ESP8266 that detects sound and activates an LED and buzzer when noise is detected.

---

## 🚀 Features
- Sound detection using sensor
- LED indication
- Buzzer alert system
- ESP8266 based project
- Easy wiring and setup

---

## 🛠️ Components Used
- ESP8266
- Sound Sensor
- LED
- Buzzer
- Jumper Wires

---

## ⚡ Working
When the sound sensor detects noise above a threshold:
- LED turns ON
- Buzzer produces alert sound

---

## 🔌 Connections
| Component | ESP8266 Pin |
|----------|--------------|
| Sound Sensor OUT | D5 |
| LED | D6 |
| Buzzer | D7 |
| VCC | 3.3V / VCC |
| GND | GND |

---

## 📂 Code
Upload the Arduino code to ESP8266 using Arduino IDE.
